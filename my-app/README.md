# Boardroom Crisis Simulator Frontend

## Current work

* Design and build the website's pages.
* Create reusable UI components, including navigation, footers, buttons, forms, and icons.

## Planned work

* Integrate the static pages and UI with the upcoming 3D models.
* Add a document reader to the lobby screen.
* Prepare the frontend connection to pass document content through the application backend to an agent API, giving the agent context.

This work covers the UI and planned connection. The API itself is being developed separately.
