# Prerecorded conversation lab verification

Measured November 7, 2026 on `experiment/ai-voice-playtest`. The user requested parallel subagents, reusable ElevenLabs recordings, conversation and turn tests, and HTML plus Markdown instructions. Recording generation, UI implementation and documentation were delegated in parallel; the main agent integrated the backend and ran the HTTP checks.

## Delivered

1. A library of **36 fixed fictional recordings** generated by ElevenLabs Flash v2.5 using **three standard premade voices**. The library covers participant contributions, uncertainty, disagreements, turn handoffs, Facilitator, IT and Journalist prompts, and public questions for T01, T02 and T03.
2. The audio lab at <http://127.0.0.1:8788/audio-lab>, with three test seats in one window, a free recorded 90 second demo, a manual five minute conversation, microphone input, optional transcription, live Vertex questions, proposals, voting, decision checks and exports.
3. [A manual guide with 17 cases](AUDIO_TEST_GUIDE.md), served as formatted HTML at <http://127.0.0.1:8788/audio-guide> and copied into Downloads as a standalone readable file.
4. Committed MP3 files, caption catalog, integrity manifest and a repeatable opt in generation script. Replaying a recording does not regenerate it. Audio and caption checksums must match before the backend serves it.

Prerecorded lines are fixed fixtures, not live replies. They do not listen or improvise. Live Gemini questions and Scribe transcription are separate, labelled actions. Playing a file alone does not commit a contribution, cast a vote or alter a decision. The free scripted demo commits its known caption only after playback completes during the same speaker's turn; it is not a speech recognition test.

## Automated verification

The full suite passed **51 playtest tests** and **31 existing tests**. The prototype demo, JavaScript syntax and DOM reference checks passed. Seven recording tests cover authentication, owner only audio access, wrong turn rejection, shared cancellation, phase and turn changes, replay idempotency without spending, explicit provisional transcription, conversion failure and file integrity. Four reproducible mocked JavaScript regression tests passed with `node playtest/tests/audio_lab_ui.test.cjs`. They cover audio initialization ordering, interrupted playback not committing script text, pending transcription room locking and stale room media cleanup. These tests use no network or paid calls.

A read only subagent review found a room switching race with in flight paid media requests. The UI was corrected to prevent room replacement while media is busy and to discard responses whose captured room no longer matches. Browser and human microphone validation remain separate from these code checks.

A live HTTP test fetched all **36 recordings** through authenticated room playback leases and matched their bytes to the manifest. Speech and Vertex reservations were unchanged after those replays, and no contributions were created. This verifies serving and replay boundaries, not audible browser playback.

A separate real timer round completed in **90.19 seconds**, with three recorded clips, three explicit transcriptions, three committed contributions, three prepared votes and one authored consequence. A wrong speaker playback request was rejected. Each transcript was confirmed provisional before a separate test command committed it. The automated harness did not perform a human review.

After the round, the live tracker finished in **2.45 seconds**. Concurrent review requests finished in **1.66 seconds** for Facilitator, **2.00 seconds** for IT and **2.45 seconds** for Journalist. All four jobs completed. The three characters returned the same valid authored consequence, so the earlier role differentiation limitation remains.
